## Selected work

### [Inkwell](https://github.com/PiduguShivaram/inkwell)
A developer workspace for designing service architectures as graphs, validating the graph, compiling it into Docker Compose projects, and inspecting runtime health and telemetry. Sketch-to-graph recognition depends on a configured vision-model endpoint; it is not presented as universally available.

**Stack:** TypeScript, Next.js, React, Vitest, Docker Compose

### [Before You Pay](https://github.com/PiduguShivaram/BEFORE_YOU_PAY_SYS)
A document-analysis decision-support application for reviewing quotations, invoices, contracts, and related financial documents. Its design separates model-assisted interpretation from deterministic validation and supports evidence-linked findings.

**Stack:** Python, FastAPI, Pydantic, pytest, Next.js, TypeScript

### [TerraTask](https://github.com/PiduguShivaram/terrtask)
An observational cyclone and geospatial intelligence prototype using archived cyclone records, satellite imagery, and atmospheric reanalysis. It distinguishes observations, derived image metrics, and reanalysis rather than treating them as interchangeable evidence.

**Stack:** TypeScript, Next.js, React, NASA GIBS, NOAA IBTrACS, ECMWF ERA5

### [MS Track Tyres](https://github.com/PiduguShivaram/ms-track-tyres)
A Vite-based motorcycle tyre storefront with product browsing, tyre-size search, catalogue interactions, and WhatsApp enquiry flows. Business inventory and availability must be confirmed by the store owner.

**Stack:** JavaScript, Vite, Three.js, GSAP
